Copy webpages exactly the way you see them

Ordinary copy throws away the values, selections and layout an assistant needs. Copy4Chat keeps them. Everything below is live — highlight any widget and watch what gets copied.

How it works, and why ordinary copy loses this

Copy4Chat is a Chrome extension that copies your selection as structured text — preserving the values typed into form fields, which options are selected, which tabs are active, and the order things actually appear on screen — so ChatGPT, Claude, Gemini and other assistants understand the page without needing a screenshot.

When you select part of a web page and press ⌘C, the browser keeps the words but throws away almost everything that gives them meaning. A chat assistant receives a flat run of text in which San Francisco is no longer the value of the destination field, merely a line that happens to follow the word “Where to?”. It cannot tell that a checkbox is ticked, that a dropdown reads “Economy”, that a date picker is open, or that a form reported an error. If a stylesheet reordered the columns, the copied text is not vague about the ordering — it is confidently wrong.

So you end up doing the work by hand: describing the page back to the assistant in your own words, or taking a screenshot and hoping it reads the small print correctly. Both are slower than copying, and both introduce exactly the kind of transcription error you were trying to avoid. Screenshots in particular are expensive for a model to process and can silently misread numbers, dates and field labels.

Copy4Chat takes a different route. It reads the live page — the actual values in the inputs, the computed layout, the accessibility information that describes icon-only buttons — and renders a compact textual representation of what you are looking at. Forms still read as forms. Tables stay tables. Side-by-side cards stay side by side. A password field is never copied; it is masked, along with card numbers, one-time codes and credential-shaped values.

Every example below runs the extension itself, in your browser, on this page. The widgets are real: type into them, switch tabs, tick boxes. Nothing here is a screenshot or a canned result.
